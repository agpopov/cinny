# Cinny 4.13.2

- Исправлена вставка скриншотов из буфера обмена Linux в X11 и Wayland.
- Кнопка «Назад» на Android возвращает из канала к списку каналов; открытые меню и треды закрываются первыми.
- После замены выделенного текста ссылкой дальнейший ввод продолжает обычный текст, включая ссылку в конце сообщения.
- Устранены перестановки и скачки списка каналов при запуске и восстановлении сессии.
- После отправки поле ввода очищается сразу, в том числе для сообщений с упоминаниями. При ошибке отправки черновик восстанавливается.
- Предпросмотр уведомлений на всех платформах учитывает форматированный текст, переносы строк, упоминания и спойлеры, скрывает служебную разметку.
- Исправлена обработка редактирования ссылок в Firefox и ошибок отправки статуса набора текста.

Корпоративные треды, опросы, уведомления и групповые упоминания сохранены.

Пакеты: Windows x64 (EXE/MSI), Linux x64 (DEB/AppImage), macOS Universal (Intel/Apple Silicon), Android (универсальный APK, отдельные APK для ARM64/ARM32/x86_64 и AAB), веб-версия.

Android подписан прежним ключом и поддерживает обновление установленного приложения. Приложение macOS имеет локальную подпись и не нотарифицировано Apple.
